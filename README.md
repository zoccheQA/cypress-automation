# Cypress Automation – End-to-End Testing for QA 🚀🚀

This repository contains E2E automation tests using **Cypress**, focused on practical UI testing to ensure software quality.

I'm Caroline, a QA passionate about continuous learning and automation best practices.  
This project was created to explore and share real-world scenarios using Cypress to make our tests more reliable and efficient.💡

---

## ⚙️ Installation

To install the project dependencies, run:
```bash
npm install
```
>
>>
---
## ⚙️ Precondition
### You must have Node.js installed on your machine.

Running

Open the Cypress UI:
```bash
npx cypress open
```

Or run the automation via command line:
```bash
npx cypress run
```

💡 Tip: Headless mode is perfect for CI/CD pipelines!
